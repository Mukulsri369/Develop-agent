# 08 — Visual & Animation Systems Audit

## 1. Executive Summary

The visual layer of Our Visible Universe Store is one of its most sophisticated assets, combining Motion React, dynamic Three.js WebGL particle simulations, CSS layered gradients, and scroll-linked orbital physics.

To transform this into a multi-tenant SaaS generator, we must decouple the generic animation primitives and performance guards from the astronomy-specific assets (planet meshes, celestial textures, and telemetry overlays).

## 4. Performance & Viewport Architecture

All visual components in the repository strictly adhere to modern web performance standards:

1. **Zero Layout Shifts**: Cutout dimensions and video container aspect ratios are fixed (`aspect-square` or locked height) to prevent cumulative layout shift (CLS).
2. **SSR Safety**: Three.js and browser Canvas operations are executed inside `useEffect` or dynamically imported after window verification, guaranteeing no SSR hydration mismatches.
3. **Hardware Acceleration**: Animations prioritize `transform` (`translate3d`, `scale`) and `opacity` to remain on the GPU compositor thread.
4. **Reduced-Motion Compliance**: All Motion transitions and Three.js simulations check `window.matchMedia("(prefers-reduced-motion: reduce)")` and fall back to static representations.
