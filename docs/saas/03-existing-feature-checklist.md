## 3. Data & Infrastructure Layer

| Area                      | Component             | Implementation Pattern                                                                                     | Status                                                    |
| ------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| **Relational Database**   | Supabase PostgreSQL   | Tables: `products`, `categories`, `site_settings`, `product_tags`, `clicks`.                               | Verified in Drizzle migration history.                    |
| **RLS Policies**          | Row Level Security    | Public read on active products; writes restricted to verified admin session (`is_admin()`).                | Enforced via migrations `0000` through `0009`.            |
| **Object Storage**        | `store-images` bucket | Private storage bucket accessed through proxy `/api/public/img/$` route so credentials never leak.         | Verified in `img.$.ts` and `admin.ts`.                    |
| **Atomic Categorization** | `category_ids` array  | Indexed `text[]` column supporting multi-category membership with backward compatibility to `category_id`. | Verified in `store.ts` and `product-categories.test.tsx`. |
