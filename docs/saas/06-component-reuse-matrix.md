# 06 — Component Reuse & SaaS Adaptation Matrix

This matrix classifies every functional component, library, and route in the codebase according to its reusability across a multi-tenant SaaS platform.

### Classification Legend

- **A**: Reusable without modification.
- **B**: Reusable with configuration extraction (extract brand strings, colors, copy, or assets into props/config).
- **C**: Requires tenant-aware refactoring (inject `tenant_id`, scope queries, or isolate storage).
- **D**: Requires security remediation (add auth verification, SSRF guards, or tighten permissions).
- **E**: Specific to the original astronomy storefront (preserved as "Tenant 0" / Reference Theme).
